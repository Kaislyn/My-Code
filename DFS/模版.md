# DFS 的核心思想与万能模板

DFS 的精髓可以用一句话概括：**“一条路走到黑，撞了南墙再回头”**。
想象你在走迷宫，遇到分叉路口，你随便选一条一直走，直到走进死胡同。这时候你退回到上一个路口（这个退回的过程叫**回溯**），尝试另一条路。



在写 C++ 代码时，所有的 DFS 基本上都长这个样子：

```cpp
void dfs(当前所处的状态/层数) {
    // 1. 终止条件（撞南墙了）
    if (到达目标状态 / 满足特定条件) {
        记录答案 或 打印结果;
        return; // 必须 return，否则会无限递归！
    }

    // 2. 遍历当前能够做的所有选择
    for (每一个可能的选择) {
        if (这个选择是合法的 && 没有被选过) {
            
            记录这个选择; (例如放入数组)
            标记为已访问; (打上标记，防止重复走)
            
            dfs(进入下一层状态); // 核心：递归进入下一步
            
            // 3. 恢复现场（回溯，回头尝试别的路）
            撤销标记; (把已访问改回未访问)
            移除这个选择;
        }
    }
}
```
